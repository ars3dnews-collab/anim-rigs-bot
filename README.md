# Animation Rigs Bot

Публикует персонажные риги для Maya и Blender в телеграм-канал. Работает в GitHub Actions — компьютер не нужен.

## Как устроено

Раз в 10 минут воркфлоу поднимает раннер, скрипт обходит источники, берёт один риг, которого ещё не было в канале, просит Gemini написать про него короткий текст по-русски и публикует пост с превью и ссылкой на автора. Список опубликованного лежит в `posted.json` и коммитится обратно в репозиторий — это и есть память бота.

Файлы ригов бот **не скачивает и не перезаливает**. У большинства лицензия это прямо запрещает: у AnimSchool в соглашении «вы не можете продавать, распространять или иначе передавать персонажа другим», у Animation Mentor «другие должны получить риг непосредственно у Animation Mentor», у Mery и CGTarian — только личное некоммерческое использование. Плюс бот в Telegram заливает максимум 50 МБ, а Rain весит 64 МБ, Snow 106 МБ, Einar 553 МБ. Поэтому в посте всегда ссылка на первоисточник.

## Настройка

**Secrets** (Settings → Secrets and variables → Actions):

| Имя | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `CHANNEL_ID` | `@animrigs` |
| `GEMINI_API_KEY` | бесплатный ключ с [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

Бот должен быть администратором канала с правом «Публикация сообщений».

Без `GEMINI_API_KEY` бот работает, но берёт описания с сайтов как есть, на английском.

## Управление

Всё через вкладку **Actions** → *Animation Rigs Bot* → *Run workflow*:

- обычный запуск — опубликовать прямо сейчас, не дожидаясь расписания;
- галочка **catch up** — пометить всё найденное как виденное и ничего не публиковать. Пригодится, если не хочешь, чтобы канал завалило архивом.

Расписание меняется в `.github/workflows/rigs.yml`, строка `cron`.

## Источники

| Источник | Что даёт |
|---|---|
| `seed_rigs.yml` | курируемый список, проверен вручную |
| Blender Studio | Rain, Snow, Vincent, Einar, каст Sprite Fright |
| Highend3d, бесплатные | 456 Maya-ригов |
| Highend3d, платные | 72 позиции с ценами |

Чего нет и почему: у **BlenderKit** в robots.txt запрет на ботов; у **CGTrader** API только для партнёров по заявке; у **Gumroad**, **ArtStation**, **Blend Swap** и **itch.io** нет ни API, ни RSS — только разбор HTML, который ломается при каждой смене вёрстки.

## Добавить риг вручную

Открываешь `seed_rigs.yml`, дописываешь блок, коммитишь. Бот подхватит при следующем запуске.

```yaml
  - name: Название рига
    url: https://ссылка-на-страницу-автора
    author: Автор
    software: Maya
    free: true
    price: ""
    license: "Некоммерческая"
    size_mb: 12.5
    thumb: https://ссылка-на-картинку.jpg
    rating: "5000 скачиваний · 4.8★"
    tags: "#maya #free"
    ru: >-
      Описание для канала. Если оно тут есть, ИИ не вызывается вообще.
```

Поле `ru` — готовый русский текст. Если его нет, бот напишет описание сам через Gemini, опираясь только на данные со страницы рига.

## Настройки

`config.py`:

| Параметр | Смысл |
|---|---|
| `MAX_POSTS_PER_RUN` | сколько ригов за один запуск |
| `SUMMARY_SENTENCES`, `SUMMARY_MAX_CHARS` | длина текста от ИИ |
| `BLENDER_STUDIO`, `HIGHEND3D_FREE`, `HIGHEND3D_PAID` | включение источников и глубина обхода |
| `REQUIRE_DESCRIPTION` | не публиковать риги без описания |
